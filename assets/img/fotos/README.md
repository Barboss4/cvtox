# Álbuns de fotos do CVTox

Adicione as fotos diretamente na pasta da edição correspondente. Os nomes das fotos internas são livres.

Use os seguintes nomes para as capas:

- `viii-cvtox/capa1.jpg`
- `vii-cvtox/capa2.jpg`
- `vi-cvtox/capa3.jpg`
- `v-cvtox/capa4.jpg`
- `iv-cvtox/capa5.jpg`
- `iii-cvtox/capa6.jpg`
- `ii-cvtox/capa7.jpg`
- `i-cvtox/capa8.jpg`

As capas também podem usar as extensões `.png`, `.webp`, `.jpeg` ou `.avif`.
